# 📉 Customer Churn Prediction System

**Sqrock IT Solutions Internship — Data Science Project 2**

A machine learning web app that predicts whether a customer will churn using Random Forest Classifier on the Telco Customer dataset.

## 🚀 Live Demo
[Click here to open the app](https://customer-churn-sqrock-2dehiqkoanqnwyjbzpmfks.streamlit.app)

## 📌 Features
- Upload any customer churn CSV dataset
- Automatic preprocessing & label encoding
- Churn distribution, tenure & monthly charges analysis
- Correlation heatmap
- Model training with Accuracy, Precision, Recall, F1
- Confusion matrix visualization
- Top 10 features affecting churn
- Predict single customer churn with interactive sliders

## 🛠️ Tech Stack
- Python, Pandas, NumPy
- Matplotlib, Seaborn
- Scikit-learn (Random Forest Classifier)
- Streamlit

## 📊 Results
- Accuracy: 79.25%
- Precision: 78%
- Recall: 79%
- F1 Score: 78%

## 📂 Dataset
Telco Customer Churn — [Kaggle](https://www.kaggle.com/datasets/blastchar/telco-customer-churn)

## ▶️ Run Locally
```bash
pip install -r requirements.txt
streamlit run app.py
```
